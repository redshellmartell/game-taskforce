The **Critic** is the last line of defence. It reviews the finished design with fresh eyes: is it original, clear, fun and balanced, and would anyone buy it? It is told to be honest, not encouraging.

- **Reads:** the brief, rules and playtest report. It may search the web to check whether the game is too close to an existing one.
- **Writes:** `critique.md` with a verdict: PASS, REVISE-MINOR, REVISE-MAJOR or KILL. A KILL moves the game to the archive.
- **Hands off to:** the Director's Office, or back to the Design Studio for a revision.

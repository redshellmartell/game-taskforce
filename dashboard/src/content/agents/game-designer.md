The **Game Designer** turns a brief into a complete, exact set of rules. It writes them so clearly that a computer could play the game from them, because the next agent literally does.

- **Reads:** the brief, and later the playtest and critic reports.
- **Writes:** `rules.md`. When a playtest or critique finds a problem, the designer revises the same file. The Director allows at most 3 of these revision loops.
- **Hands off to:** the Playtest Lab.
- **Tools:** it can read and write files but has no web access. It designs from the brief, not from copying other games.
